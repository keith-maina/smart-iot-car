    How this works

    The ESP32 car sends its distance and state over WiFi using MQTT. This page listens, shows it live, and sends commands back.

    • 🟢 GO: path is clear
    • 🟡 SLOW: obstacle getting close
    • 🔴 STOP: obstacle too close
